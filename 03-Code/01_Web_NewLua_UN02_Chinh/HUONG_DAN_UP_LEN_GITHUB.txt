--------------------------------------------------------------------------------
CÁCH 1: KÉO THẢ TRỰC TIẾP TRÊN TRÌNH DUYỆT (ĐƠN GIẢN NHẤT)
--------------------------------------------------------------------------------
1. Truy cập https://github.com và đăng nhập tài khoản.
2. Bấm nút màu xanh "New" ở góc trái để tạo repository mới.
3. Điền thông tin:
   - Repository name: Newlua02_UN
   - Chọn: Public (bắt buộc để kích hoạt web miễn phí).
   - KHÔNG cần tích vào "Add a README file".
4. Bấm "Create repository".
5. Ở trang mới xuất hiện, bấm vào dòng chữ: "uploading an existing file".
6. Kéo toàn bộ các file & thư mục trong Newlua02_UN này vào:
   - index.html
   - styles.css
   - data.js
   - app.js
   - thư mục assets (chứa ảnh và voucher)
7. Đợi tải xong -> Kéo xuống dưới cùng bấm nút "Commit changes".
8. Bật GitHub Pages:
   - Vào Settings (bánh răng) -> Menu bên trái chọn "Pages".
   - Tại "Build and deployment" -> Mục Branch chọn "main" -> Thư mục giữ nguyên "/(root)".
   - Bấm "Save".
9. Đợi 1-2 phút, load lại trang sẽ nhận link:
   👉 https://[ten-tai-khoan].github.io/Newlua02_UN/

--------------------------------------------------------------------------------
CÁCH 2: DÙNG LỆNH GIT TRÊN MÁY TÍNH (NHANH CHO LẦN CẬP NHẬT SAU)
--------------------------------------------------------------------------------
Mở terminal/PowerShell tại thư mục Newlua02_UN và gõ:
   git init
   git add .
   git commit -m "feat: Khoi tao web Newlua02_UN"
   git branch -M main
   git remote add origin https://github.com/[ten-tai-khoan]/Newlua02_UN.git
   git push -u origin main
